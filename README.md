## ✨ ระบบทำอะไรได้ (เมนู 7 รายการในแอป = 6 หน้าฟีเจอร์ + หน้ารวมงาน)

| หน้าในแอป | รายละเอียด |
|---|---|
| 📊 **Dashboard** · ภาพรวมระบบ | 6 ตัวชี้วัด (ผู้ใช้ / รุ่น / LIKES / RATED / ยี่ห้อ / ระดับราคา) + กราฟ 10 รุ่นยอดนิยม + สัดส่วนระดับราคา + โปรไฟล์ผู้ใช้ (รสนิยม · สนใจแล้ว · ดาวที่ให้) + คำแนะนำล่าสุด |
| ✨ **Recommendations** · แนะนำมือถือ | การ์ดรุ่นที่แนะนำ **พร้อมภาพสินค้าจริง** + คะแนน + เหตุผล (เพื่อนคนไหน / เพราะสนใจรุ่นไหน / ดาวเฉลี่ย) + ตารางความคล้าย Jaccard และเลือกได้ 5 วิธีให้คะแนน |
| 🔎 **Phone Search** · ค้นหารุ่นมือถือ | ค้นหา/กรองตามยี่ห้อและระดับราคา + เรียงตามคนสนใจ/ดาวเฉลี่ย แสดงการ์ดพร้อมภาพ |
| 📝 **Like & Rate** · ถูกใจ / ให้คะแนน | เพิ่ม/ลบความสนใจ และ **ให้คะแนนดาว 1.0–5.0** (เขียนลงฐานข้อมูลจริง) แล้วเห็นคำแนะนำ **ก่อน–หลัง** เปลี่ยนทันทีโดยไม่ต้องเทรนใหม่ |
| 🕸️ **Graph Explorer** · สำรวจโครงสร้างกราฟ | วาดกราฟผู้ใช้ ↔ รุ่นมือถือ + เส้นทางการตัดสินใจของอันดับ 1 + **ตารางความสัมพันธ์ (edge) ทั้งหมด** + **ช่องรันคำสั่ง Cypher เอง** (อ่านข้อมูลเท่านั้น) |
| 📚 **Index & Links** · งานทั้งหมด (Index) | หน้า hub แบบการ์ด **มีปุ่ม gradient** ต่อการ์ด: งานชิ้นนี้ · โน๊ตบุ๊ก Colab · สไลด์ · หน้า index รวมงาน (ดึงข้อมูลจากหน้า index อัตโนมัติด้วย `tools/build_homework_index.py`) + งานในวิชานี้/หมวดอื่น |
| ⚙️ **Admin & Setup** · ผู้ดูแลระบบ | โครงสร้างกราฟ (schema) · ปุ่ม **รีโหลดข้อมูลตัวอย่างแบบ idempotent** (MERGE กดซ้ำได้) · ล้างโหนดที่ไม่มีเส้นเชื่อม · ดาวน์โหลดข้อมูล CSV · สรุปวิธีทำงานสำหรับผู้ตรวจ |

**วิธีให้คะแนน 5 วิธี** (เลือกได้ในหน้า Recommendations)
1. **ถ่วงน้ำหนัก (Jaccard)** — `คะแนน = Σ Jaccard(เรา, คนที่สนใจรุ่นนั้น)`
2. **นับโหวตเพื่อน** — 1 คน = 1 เสียง ต่อ 1 รุ่น (`count(DISTINCT other)`)
3. **ตามยี่ห้อ/ราคา** — นับรุ่นที่เราเคยสนใจซึ่งใช้ยี่ห้อเดียวกันและอยู่ระดับราคาเดียวกัน (แก้ cold start)
4. **ผสม** — `0.6 × สัญญาณเพื่อน + 0.4 × สัญญาณยี่ห้อ/ราคา` (normalize 0–1)
5. **ถ่วงด้วยคะแนนดาว** — `Σ ( Jaccard(เรา, เพื่อน) × ดาวที่เพื่อนให้รุ่นนั้น ÷ 5 )`
   ใช้ความสัมพันธ์ `RATED {stars}` — คนที่ให้ 5 ดาวมีน้ำหนักมากกว่าคนที่ให้ 2 ดาว

## 🧩 โครงสร้างกราฟ

```
(User {user, age, group})
    │  [:LIKES]                    → ความสนใจ (1 เส้น = 1 รุ่นที่สนใจ)
    │  [:RATED {stars}]            → คะแนนดาว 1.0–5.0
    ▼
(Phone {phone_id, model, brand, tier, image})
    │ [:BY_BRAND] → (Brand {name})
    │ [:IN_TIER]  → (Tier  {name})
```

**คำถามหลัก 3 hop** — `(ผู้ใช้)-[:LIKES]->(รุ่น)<-[:LIKES]-(คนอื่น)-[:LIKES]->(รุ่นใหม่)`
คือ "คนที่สนใจรุ่นเดียวกับเรา ยังสนใจรุ่นอะไรอีกที่เรายังไม่สนใจ" (แล้วถ่วงด้วย `RATED` ถ้าต้องการ)

## 🚀 วิธีรัน

### 1) ทดลองในเครื่อง (ไม่ต้องมี Neo4j ก็ได้)
```bash

```
ถ้าต่อ Neo4j ไม่ได้ แอปจะสลับไปใช้ **backend สำรองในหน่วยความจำ** (ข้อมูลชุดเดียวกัน) ให้อัตโนมัติ
ดูวิธีตั้ง Neo4j ในเครื่องแบบไม่ต้องใช้ Docker: [`docs/local-neo4j.md`](docs/local-neo4j.md)

### 2) ต่อ Neo4j จริง (ในเครื่อง)
```bash
py -3.13 tools/load_neo4j.py bolt://127.0.0.1:7687 neo4j <password> phones
py -3.13 tools/consistency_test.py bolt://127.0.0.1:7687 neo4j <password> phones
```

### 3) ต่อ Neo4j จริง — ในเครื่อง หรือ Neo4j Aura Free บนคลาวด์
ในเครื่อง: สร้างไฟล์ `.streamlit/secrets.toml` ( **ห้าม commit** — มี `.example` ให้ดูตัวอย่าง)
```toml
NEO4J_URI = "neo4j+s://xxxxxxxx.databases.neo4j.io"   # หรือ bolt://127.0.0.1:7687 ในเครื่อง
NEO4J_USER = "neo4j"
NEO4J_PASSWORD = "รหัสผ่านของ instance"
NEO4J_DATABASE = "neo4j"                                # ในเครื่องใช้ "phones"
```
บน Streamlit Cloud: ใส่ค่าเดียวกันนี้ที่ **Settings → Secrets** ของแอป (ไม่ต้อง commit)
แล้วกด **🔄 รีโหลดข้อมูลตัวอย่าง** ในหน้า *Admin & Setup* เพื่อโหลดข้อมูลขึ้น Aura
- Aura Free หลับเมื่อไม่ใช้ 3 วัน → เปิดครั้งแรกอาจรอ ~20-30 วิ (โค้ดลองซ้ำให้เอง)

- ฐานข้อมูลว่างก็ไม่พัง: ทุกหน้าขึ้น 0 แล้วชี้ไปที่ปุ่มโหลดข้อมูล
