## ✨ ระบบทำอะไรได้

| หน้าในแอป | รายละเอียด |
|---|---|
| 🎯 **แนะนำมือถือ** | การ์ดรุ่นที่แนะนำ **พร้อมภาพสินค้า** + คะแนน + เหตุผล (เพื่อนคนไหน / เพราะคุณสนใจรุ่นไหน) และตารางความคล้าย Jaccard |
| 📱 **คลังรุ่นทั้งหมด** | 23 รุ่น พร้อมภาพ ค้นหา/กรองตามยี่ห้อ |
| 🕸️ **โครงสร้างกราฟ** | วาดกราฟผู้ใช้ ↔ รุ่นมือถือ (ตามด้วยเส้นทาง 3 hop ที่ระบบเดิน) + ผังการตัดสินใจของอันดับ 1 |
| 🧪 **เดโมสด** | เพิ่ม/ลบความสนใจในฐานข้อมูลจริง แล้วเห็นผลก่อน–หลังเปลี่ยนทันที (ไม่ต้องเทรนโมเดลใหม่) |
| ℹ️ **เกี่ยวกับระบบ** | สถาปัตยกรรม สูตรให้คะแนน และสถานะการเชื่อมต่อฐานข้อมูล |

**วิธีให้คะแนน 4 แบบ** (เลือกได้ในแถบข้างของแอป)
1. **ถ่วงน้ำหนัก (Jaccard)** — `คะแนน = Σ Jaccard(เรา, คนที่สนใจรุ่นนั้น)`
2. **นับโหวตเพื่อน** — 1 คน = 1 เสียง ต่อ 1 รุ่น (`count(DISTINCT other)`)
3. **ตามยี่ห้อ/ราคา** — นับรุ่นที่เราเคยสนใจซึ่งใช้ยี่ห้อเดียวกันและอยู่ระดับราคาเดียวกัน
4. **ผสม** — `0.6 × สัญญาณเพื่อน + 0.4 × สัญญาณยี่ห้อ/ราคา` (แก้ปัญหา cold start)

## 🧩 โครงสร้างกราฟ

```
(User {user, age, group})
    │  [:LIKES]                    (Phone {phone_id, model, brand, tier, image})
    ▼                                   │            │
(Phone) ──────────────◄────────────────┘            │ [:IN_TIER]
    │                                              ▼
    │ [:BY_BRAND]                             (Tier {name})
    ▼
(Brand {name})
```

**คำถามหลัก 3 hop** — `(ผู้ใช้)-[:LIKES]->(รุ่น)<-[:LIKES]-(คนอื่น)-[:LIKES]->(รุ่นใหม่)`
คือ "คนที่สนใจรุ่นเดียวกับเรา ยังสนใจรุ่นอะไรอีกที่เรายังไม่สนใจ"

## 🚀 วิธีรัน

### 1) ทดลองในเครื่อง (ไม่ต้องมี Neo4j ก็ได้)
```bash
py -3.13 -m streamlit run app.py        # เปิด http://127.0.0.1:8779
```
ถ้าต่อ Neo4j ไม่ได้ แอปจะสลับไปใช้ **backend สำรองในหน่วยความจำ** (ข้อมูลชุดเดียวกัน) ให้อัตโนมัติ
ดูวิธีตั้ง Neo4j ในเครื่องแบบไม่ต้องใช้ Docker: [`docs/local-neo4j.md`](docs/local-neo4j.md)

### 2) ต่อ Neo4j จริง (ในเครื่อง)
```bash
py -3.13 tools/load_neo4j.py bolt://127.0.0.1:7687 neo4j <password> phones
py -3.13 tools/consistency_test.py bolt://127.0.0.1:7687 neo4j <password> phones
```

### 3) ต่อ Neo4j Aura (คลาวด์ฟรี) — สำหรับเดโมตอนนำเสนอ
สร้างไฟล์ `.streamlit/secrets.toml` ( **ห้าม commit** — มี `.example` ให้ดูตัวอย่าง)
```toml
NEO4J_URI = "neo4j+s://xxxxxxxx.databases.neo4j.io"
NEO4J_USER = "neo4j"
NEO4J_PASSWORD = "รหัสผ่านของ instance"
NEO4J_DATABASE = "neo4j"
```

### 4) Deploy ขึ้น Streamlit Community Cloud (ฟรี)
ดูขั้นตอนใน [`docs/deploy-streamlit-cloud.md`](docs/deploy-streamlit-cloud.md) — repo นี้ deploy ได้ทันที
โดยไม่ต้องแก้โค้ด: ถ้ามี secrets ของ Neo4j จะใช้ฐานข้อมูลกราฟ ถ้าไม่มีจะใช้ **โหมดสาธิตในหน่วยความจำ**
(ข้อมูลชุดเดียวกัน, แยกต่อผู้เข้าชม 1 คน) พร้อมภาพสินค้าครบ

### 5) โน๊ตบุ๊กสำหรับส่ง (Colab)
`notebooks/PhoneRecommender_Neo4j_007.ipynb` — รันได้บน Colab ทุกเซลล์ มีผลลัพธ์จริงฝังอยู่ในไฟล์

```bash
py -3.13 tools/build_notebook.py            # สร้างโน๊ตบุ๊กเวอร์ชันส่ง
py -3.13 tools/run_notebook.py <notebook>   # รันทุกเซลล์กับ Neo4j ในเครื่อง
```

## ⚖️ ความต่างจากงานตัวอย่างในวิชา
งานตัวอย่างในวิชา (*GraphBook*) เป็นระบบแนะนำ**หนังสือ** งานชิ้นนี้จึงต่างทั้งโดเมนและวิธีคิด:

| ประเด็น | งานตัวอย่าง (GraphBook) | ระบบของเรา |
|---|---|---|
| โดเมน | หนังสือ | **มือถือ** |
| ชนิดโหนด | นักเรียน / หนังสือ / หมวด / ผู้แต่ง | ผู้ใช้ / มือถือ / **ยี่ห้อ / ระดับราคา** |
| สัญญาณความสนใจ | ยืมหนังสือ + ให้ดาว | "สนใจรุ่นไหน" อย่างเดียว (ไม่ใช้ดาว) |
| สัญญาณเนื้อหา | หมวดหนังสือ | **ยี่ห้อ + ระดับราคา** (โหนด `Brand`, `Tier`) |
| สูตรให้คะแนน | heuristic ถ่วงคงที่ (เพื่อน×3+หมวด×2+ความนิยม×0.2+ดาว×0.5) | Jaccard ต่อคน + นับโหวต + content + ผสม (normalize 0–1) |
| กันนับซ้ำ | manual | `count(DISTINCT other)` ใน Cypher |
| ภาพในระบบ | ไม่มี | **การ์ดพร้อมภาพสินค้าจริงทุกผลลัพธ์** |
| การตรวจสอบ | — | เทส 2 backend + assertion ในโน๊ตบุ๊ก |
